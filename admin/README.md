# Painel Administrativo — Cervejaria Rodada

Este diretório contém a estrutura do painel administrativo da Cervejaria Rodada.

## Objetivo

Permitir que o administrador gerencie o conteúdo do site sem precisar editar código.

## Módulos do painel

- Dashboard
- Produtos
- Pedidos e orçamentos
- Leads
- Conteúdo do site
- Imagens
- Configurações

## Segurança

O acesso ao painel será protegido por autenticação e permissão de administrador utilizando Supabase.
